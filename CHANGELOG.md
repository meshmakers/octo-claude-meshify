Initial release.

- `blueprint-packaging` — blueprint manifest + seed authoring, install/update semantics, Application workloads and the web-app Helm chart contract, examples
- `mesh-data-layer` — per-tenant GraphQL API usage, machine-to-machine auth, client wire conventions, example operations
